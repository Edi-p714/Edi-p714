Como Analista QA, utilizo GitHub para organizar y versionar la documentación técnica de calidad. Aquí destaco:
1.  **Casos de Prueba:** Documentación estructurada de flujos funcionales y de regresión.
2.  **Reportes de Bugs:** Gestión del ciclo de vida de defectos y matrices de trazabilidad.
3.  **Scripts de Automatización:** Mis primeros pasos implementando automatización para optimizar tareas.
